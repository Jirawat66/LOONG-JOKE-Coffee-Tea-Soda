# Button

ปุ่มกดทั่วไป มี 3 แบบ ปุ่ม `primary` สีอิฐมีเงาสติกเกอร์ ใช้ได้หน้าละหนึ่งปุ่ม สำหรับสิ่งที่หน้านั้นมีไว้ทำ เช่น "เพิ่มลงตะกร้า · 120 ฿" หรือ "สั่งเลย"

- `secondary` เป็นป้ายเม็ดยาสีเนยตัดขอบ ใช้กับคำสั่งรอง เช่น "ดูตะกร้า"
- `quiet` เป็นตัวอักษรสีอิฐ ใช้กับ "ยกเลิก" หรือ "ออกจากระบบ"
- ข้อความเริ่มด้วยคำกริยา สั้น และไม่เกินหนึ่งบรรทัด
- ความสูงอย่างน้อย 48px เพื่อให้กดด้วยนิ้วได้ง่าย
- ผู้ใช้ส่ง `onClick` และ `disabled` ได้เหมือนปุ่ม HTML ปกติ
