# Chip

ตัวเลือกแบบเลือกได้ทีละอันในกลุ่ม ใช้เลือกความหวาน: ไม่หวาน / หวานน้อย / ปกติ / หวานมาก

- chip ที่ถูกเลือกจะเป็นพื้นสีเนยตัดขอบดำ ส่วน chip ที่ยังไม่เลือกเป็นพื้นยกตัดขอบบาง
- ผู้ใช้เป็นคนจำว่า chip ไหนถูกเลือก แล้วส่ง `selected` มาให้
- ตั้ง "ปกติ" เป็นค่าเริ่มต้น ลูกค้าส่วนใหญ่จะได้ไม่ต้องกดเพิ่ม
