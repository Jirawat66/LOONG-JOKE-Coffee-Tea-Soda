# MenuCard

การ์ดเมนูหนึ่งรายการ แสดงรูป ชื่อ ชื่อไทย และราคา ส่งข้อมูลจาก `data/menu.json` ได้โดยตรง (`name`, `nameTh`, `price`, `image`, `available`)

- ถ้าเมนูไม่มีรูป (`image` ว่าง) การ์ดจะแสดงกรอบสีแอปริคอตพร้อมอักษรตัวแรกของชื่อแทน
- ถ้า `available` เป็น `false` การ์ดจะจางลง ขึ้น badge "หมด" และกดไม่ได้
- บนมือถือวางการ์ด 2 คอลัมน์ ห่างกัน `space-4`
- ผู้ใช้ส่ง `onSelect` สำหรับเปิดหน้าเลือกความหวานและจำนวน
