# LOONG JOKE

Design system ของร้าน LOONG JOKE Coffee Tea Soda สำหรับเว็บสั่งเครื่องดื่มผ่าน QR code ที่โต๊ะ ถอดแบบมาจากป้ายเมนูของร้าน (`assets/Reference`) และโลโก้ (`assets/Logos`)

ภาพรวม: ป้ายเมนูกระดาษครีม หัวป้ายสีอิฐ ตัวอักษรหนาตัวใหญ่ และป้ายเม็ดยาสีเนยตัดขอบดำ อารมณ์เป็นกันเองแบบร้านเล็ก ไม่หรู ไม่เรียบเกินไป

## เสียงและถ้อยคำ

- เขียนภาษาไทยเป็นหลัก สั้น ตรง และสุภาพแบบคนในร้านคุยกับลูกค้า เช่น "เพิ่มลงตะกร้า" หรือ "สั่งเลย" ไม่ใช้ "ยืนยันการทำรายการ"
- ชื่อเมนูใช้ตามป้าย: ชื่ออังกฤษเป็นบรรทัดหลัก (สไตล์ `item`) แล้วตามด้วยชื่อไทยเป็นบรรทัดรอง (สไตล์ `body-sm` สี `ink-muted`) ถ้าเมนูมีชื่อภาษาเดียวก็ใช้บรรทัดเดียว
- ราคาเขียนเป็น "60 ฿" ใช้สไตล์ `price` สี `brick`
- ข้อความผิดพลาดบอกว่าเกิดอะไรขึ้นและต้องทำอะไรต่อ เช่น "รหัสไม่ถูกต้อง ลองใหม่อีกครั้ง" ไม่ต้องขอโทษ

## สี

| บทบาท | Token | ใช้ที่ไหน |
| --- | --- | --- |
| พื้น | `surface`, `surface-raised` | พื้นหน้าเว็บสีครีม และพื้นการ์ดที่ยกขึ้นมา |
| แบรนด์ | `brick` | ปุ่มหลัก ราคา หัวหมวด แถบหัวเว็บ |
| ป้ายเม็ดยา | `butter` | chip ที่ถูกเลือก ปุ่มรอง badge "ใหม่" |
| โลโก้ | `apricot`, `navy` | ที่ว่างแทนรูปเมนู และเลขโต๊ะ |
| กำลังทำ | `apricot` | badge "กำลังทำ" และปุ่ม "เริ่มทำ" ที่หน้าร้าน |
| สำเร็จ | `leaf` | badge "เสร็จแล้ว" และปุ่ม "เสร็จแล้ว" ที่หน้าร้าน เท่านั้น |

กฎ:
- บนพื้น `butter` และ `apricot` ใช้ตัวอักษร `ink-fixed` เสมอ เพราะสองสีนี้ยังสว่างแม้ในโหมดมืด
- บนพื้น `brick` ใช้ `on-brick` และบนพื้น `leaf` ใช้ `on-leaf`
- หน้าหนึ่งมีปุ่ม `brick` ได้แค่ปุ่มเดียว คือปุ่มของสิ่งที่หน้านั้นมีไว้ทำ เช่น "เพิ่มลงตะกร้า"
- `leaf` หมายถึงเสร็จหรือพร้อมเท่านั้น ห้ามใช้ตกแต่ง
- ปุ่มเปลี่ยนสถานะออเดอร์ใช้สีของสถานะถัดไปพร้อมไอคอน: "เริ่มทำ" พื้น `apricot` ไอคอน ▶, "เสร็จแล้ว" พื้น `leaf` ไอคอน ✓ ไม่ใช้ `brick` เพราะบอร์ดมีหลายใบ

## ตัวอักษร

- **League Spartan** (`display`) สำหรับชื่อร้านและหัวหมวด ตัวหนา ตัวพิมพ์ใหญ่ เหมือนป้าย "LOONG JOKE" และ "ICE COFFEE"
- **Prompt** (`sans`) สำหรับเนื้อหาทั้งหมด รองรับไทยและอังกฤษ
- ตัวไทยในหัวข้อจะใช้ **Kanit** แทนโดยอัตโนมัติ เพราะ League Spartan ไม่มีตัวไทย
- ฟอนต์ทั้งหมดโหลดจาก Google Fonts:
  `https://fonts.googleapis.com/css2?family=League+Spartan:wght@600;700;800&family=Kanit:wght@500;700&family=Prompt:wght@400;500;600&display=swap`
- ระยะห่างระหว่างตัวอักษร (letter-spacing) ใช้กับตัวพิมพ์ใหญ่ภาษาอังกฤษเท่านั้น (สไตล์ `label` และ `item`) ห้ามใช้กับภาษาไทย เพราะสระและวรรณยุกต์จะแยกจากพยัญชนะ
- ตัวอักษรบนมือถือลูกค้าต้องไม่เล็กกว่า 16px ยกเว้นบรรทัดรอง

## รูปทรง

- **ป้ายเม็ดยาตัดขอบ** เป็นรูปทรงประจำแบรนด์: ขอบมน `radius-pill` พื้น `butter` เส้นขอบ `stroke-bold` สี `ink` มาจากป้าย "OPEN AT" บนเมนู
- **เงาแบบสติกเกอร์** `shadow-sticker` เป็นเงาแข็ง เยื้องไปมุมขวาล่าง ไม่เบลอ ใช้กับปุ่มหลักเท่านั้น
- แถบหัวเว็บสี `brick` มีมุมล่างซ้ายมน `radius-lg` เหมือนหัวป้ายเมนู
- การ์ดใช้เส้นขอบบาง `stroke-hair` สี `line` ไม่ใช้เงา
- ระยะห่างใช้ตามสเกล `space-*` ส่วนขอบซ้ายขวาบนมือถือคือ `space-4`

## รูปภาพ

- รูปเมนูเป็นรูปแนวตั้ง 3:4 ถ่ายแก้วพลาสติกในแสงอุ่น ให้ครอปด้วย `object-fit: cover` อย่ายืดรูป
- เมนูที่ยังไม่มีรูป (ใน `data/menu.json` คือ `"image": ""`) ให้แสดงกรอบสี `apricot` แทน ข้างในใส่อักษรตัวแรกของชื่อเมนูด้วยฟอนต์ `display` สี `navy` ห้ามใช้รูปของเมนูอื่นแทน
- ใช้โลโก้ตามไฟล์จริงเท่านั้น ห้ามวาดใหม่หรือเปลี่ยนสี

## ไอคอน

ร้านยังไม่มีชุดไอคอน ให้ใช้ข้อความแทนเกือบทั้งหมด ถ้าจำเป็นต้องใช้ (เช่น ปุ่มตะกร้า หรือปุ่ม − / +) ให้ใช้ไอคอนเส้นแบบเรียบ ความหนาเส้นเท่า `stroke-mid` สีเดียวกับข้อความรอบข้าง ห้ามใช้ emoji

ดาวสีเหลืองที่อยู่บนป้ายเมนู ใช้เป็นการตกแต่งบนป้ายกระดาษเท่านั้น ไม่ต้องใส่ในเว็บ

## Components

| ชื่อ | ใช้ทำอะไร |
| --- | --- |
| `Button` | ปุ่มหลักสีอิฐ ปุ่มรองสีเนย และปุ่มแบบเรียบ |
| `Chip` | ตัวเลือกความหวานแบบเลือกได้ทีละอัน |
| `Stepper` | ปุ่มลด/เพิ่มจำนวนแก้ว |
| `MenuCard` | การ์ดเมนูหนึ่งรายการ รองรับเมนูที่ไม่มีรูปและเมนูที่หมด |
| `StatusBadge` | สถานะออเดอร์ในหน้าร้าน: ใหม่ / กำลังทำ / เสร็จแล้ว |
